# LLM Prompt 约定与调用清单

统一规范见根目录 [AGENTS.md](../AGENTS.md#llm-prompt-编写规范)。Prompt 使用 Markdown，输出仍遵守各业务 JSON 契约。
模板负责目标、调研步骤、表格用途和关键口径；领域投影负责选取结论，`llm/prompting.py` 负责 CSV 展示和安全围栏。
不是把整个数据库对象或原始 JSON 换成 CSV：先删除无关字段和重复原始数据，再生成表。

## 调用范围

| 业务 / 调用类型 | 输入投影与表格用途 | 研究边界 |
| --- | --- | --- |
| 信号中心 V2 初筛 / 最终 | 候选、Trend、ETF、行业、共振整体结论；共享市场背景 | 允许网页及 FA 只读核查，冻结字段的结构化引用仍只能引用输入 |
| 信号中心 V1 历史续跑初筛 / 最终 | 原候选与来源结论，移除调度依赖和筛选计划 | 保留不联网、只解释冻结资料的历史契约及原数量限制 |
| 持仓复盘 | 每笔持仓、现金与估值、日线/分钟窗口摘要、指数、精简预演 | 允许网页及 FA 核查；仅限已有持仓、指数和相关行业；数量/现金硬约束依然校验原冻结值 |
| 财报资料研究 | 单公司财季、共识、指引和历史财报，不附价格背景 | 主动网页研究，可参考 FA；来源是否可采信仍以原 transport 证据规则为准 |
| 财报前瞻 | 共识/研究来源与事实、个股/市场统计摘要，不附原始K线 | 仅使用冻结资料，不再次查询 FA 或网页，避免两阶段事实漂移 |
| 期权解释 / 日报 | 既有评分和局限；全部异常相关合约与关键事件 / 15个主要异常证券 | 不新增通用网页搜索；可用 FA 核查截止时点前背景，不替换评分或编造方向 |
| 日历重要性评分 | 事件身份、时间、内容与公司规模，移除无关报价/EPS重复字段 | 不新增网页搜索；可参考 FA 公司/行业资料，关注价值不是收益预测 |

共5个业务域、10处调用（包含V1的两处历史兼容调用）；所有调用仍经过 `LLMClient`。

## 表格与精度

通用表格用输入内唯一短 `ref` / `parent_ref` 关联对象列表，点分列名是同一对象的子字段；公共背景只出现一次。
标量列表在单元格内用JSON数组转义，不再逐项创建关联行；[]、NA、0、false、空对象{}保留各自语义，保留字字符串使用JSON引号。
证券身份、业务日期和合约/持仓ID保留，各模板解释实际表用途。CSV会正确引用逗号/换行，并延长围栏以容纳数据内的反引号。
通用数字绝对值≥1时最多2位小数，较小非零值4位有效数字，避免小量级EPS/波动率被显示为0。
信号中心 V2 沿用比率4位小数、其他2位的精确证据协议。NaN/Infinity视为缺失。

持仓窗口摘要还包含最近1/3根收盘变化、末收盘距5根均价与窗口高点偏离、最近3根量/此前3根量。
指标基于已冻结闭合序列，缺数据/不足所需窗口/零量分母时NA，不推断突破或回踩确认。
财报前瞻使用已有 return_pct、volatility、ATR 等摘要，不重新计算指标。
输入压缩不改变模型输出校验、数据归属或交易约束；对话里的表格展示值不覆盖原始业务数据。
不设置应用层固定字符拒绝条件，也不替换为其他任意上限；字符/Token统计仅供观察，不截断名单或关键证据。供应商真实上下文限制、超时、输出校验和正常错误处理继续生效。

## FA 补充信息

通过执行环境已有 FA skill 只读查询相关范围，不在 Prompt 写死调用方法或凭据。
标注来源、日期和正式/预演状态；不访问其他用户私有数据、不修改数据、不触发任务、不以未来信息解释历史。
补充发现不能替换冻结持仓、排名、评分，FA 查询不等于网页搜索确认。
没有工具的 API 通道仍可基于输入完成任务，并明确未核查的局限；本次改动没有为 API 增加 FA 工具。

财报资料缓存版本改为 `earnings-v3-fact-refs`，日历评分改为 `v3-tables`，避免误用旧 Prompt 的缓存。
信号中心保留输出契约版本及成功初筛桶，未完成调用采用新展示模板；已完成结果不自动重算。
期权已有缓存解释也不自动重算。

## 验证

测试覆盖CSV关联、标量列表、引号与围栏、低值精度、缺失语义、长输入正常调用、关键事件保留、事实引用、摘要走势、投影不修改输入、旧任务续跑和输出契约。
本次没有执行真实 LLM 效果对比或生产部署。Markdown 结构参考 [OpenAI Prompt engineering](https://developers.openai.com/api/docs/guides/prompt-engineering)，具体字段和业务边界以本仓库代码为准。

## 证据与审计

期权投影保留去重后的关键events（类型、严重度、观测值、reference、来源与时间）；期限倒挂只保留所需前/后期限、天数和IV，旧版只给IV时展示同来源匹配期限，不伪造唯一匹配。
异常合约按关联事件重要性排列，保留报价/OI时效及来源冲突；完全相同记录去重，普通无异常合约及无关诊断不发送。来源与限制说明共享定义，合约通过event_ids引用触发事实。
财报前瞻独立投影将guidance/operating/research中完全相同的事实只保留一次，用内容身份fact_id引用，来源使用source_id；不做文本相似合并。
完整context仍写审计快照并参与input_hash（仍排除滚动data_cutoff）；研究bundle继续由research_id关联保存，缓存版本随投影协议更新。

代表性完整Prompt的前后统计及证据核对见 [PR493样本对比](pr493-prompt-comparison.md)。
