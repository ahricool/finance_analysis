# A 股免费分钟 K 线选型与验证

2026-10-23 调研与盘中只读测试；仅调整 CN 的 1min，US/HK 和 CN 5min 的调用契约保持独立。

## 调用方与数据边界

- Streamer：自选与未清仓持仓并集，独立采集分钟 OHLC，写 Redis。
- `a_share_pre_close_review`：通过 MarketDataService 读 1min，优先 Streamer 缓存；无缓存时走同一免费源链。
- `intraday_confirmation`：显式调用既有 `sina_minute` 的 5min，本次不改变此接口。
- 前端自选/持仓展开图及 API 只读 Redis，不因打开图表增加上游请求。
- Fuyao 报价仍供实时报价、当前分钟预览和日内方向使用；不再通过报价拟合/持久化 CN 分钟 OHLC。

## 短时测试结果

北京时间约 11:18–11:21，从开发宿主机和正在运行的生产 server 容器分别发起只读请求。
每轮六个样本，重复三轮，共每源每环境 18 次；每个测试进程的全部源合计限速 2 QPS、最多三个并发。
样本包含生产 CN 采集池中的三只股票，以及 ETF、上证指数和北交所股票。
生产池去重为 3 个 CN 标的；未修改生产配置、数据库、Redis 或运行服务。

| 源 | 本机 HTTP 成功 | 生产容器 HTTP 成功 | 生产有效分钟序列 | 生产成功请求 P50 / P95 |
| --- | --- | --- | --- | --- |
| 新浪 | 18/18 | 17/18 | 17/18 | 0.754s / 1.403s |
| 腾讯 m1 | 18/18 | 18/18 | 沪深/ETF/指数 15/15；BJ 0/3 | 0.553s / 1.285s |
| 东财 | 3/18 | 0/18 | 0/18 | N/A |
| easyquotation 旧分时 URL（HTTPS） | 15/18 | 15/18 | 0：成功响应为旧日期且无 OHLC | 0.516s / 0.644s |

P95 使用成功请求的 nearest-rank 定义，失败另计。新浪本机有一次 7.317s 长尾，生产有一次超时，
因此不能因为平均耗时较低就取消超时和备用源。HTTP 200、返回非空、日期新鲜与 OHLC 有效分别判断。
新浪与腾讯对已闭合分钟的部分 OHLCV 存在差异，不承诺交易所逐笔重建精度，不跨源拼接某根线的字段。

复测脚本不属于离线测试：

```bash
uv run python scripts/check_cn_minute_sources.py --rounds 3 --qps 2
# 在生产网络执行同一个无密钥脚本；不会向容器复制源码或写业务数据
docker exec -i finance-analysis-server python - < scripts/check_cn_minute_sources.py
```

## 运行参数与失败语义

- 报价继续每 5 秒；分钟线独立任务每 15 秒发起一轮，不重叠，也不阻塞报价。
- 每个源全进程至多 1 QPS，最多 3 个共享 HTTP worker；每批至多 20 标的，较大池轮转调度。
  3 标的正常负载约 0.2 QPS；全部触发备用时每源约 0.2 QPS。池扩大后周期取决于 1 QPS 节流与请求耗时。
- HTTP connect/read 分别最多 2s/6s，继承整批 deadline。不在同轮反复重试同一源。主源最多使用整批剩余预算的 60%，为备用源预留时间。
- 主源超时、空响应、无效 OHLCV 或闭合线超过容忍窗口（2 分钟）时，仅对失败标的请求腾讯。
  开盘不足一分钟时不强求闭合线；午休/收盘以最后一个交易分钟为目标，收到闭合尾线才停止轮询。
  尾线一直缺失时在收盘/午休三分钟后降低至五分钟重试，不补造零量分钟。
- 两源失败保留旧数据及真实时间，健康状态降级；BJ 主源失败时如实不可用，不再引入第三源。
- 新旧源切换整段替换当日窗口。CN API 通过 `full_snapshot=true` 返回全窗口，前端替换数据而保留当前选择，
  从而传播源切换、历史修订和删除；US 仍使用增量返回。
- 所有分钟按区间开始时间存 UTC；排除单独 09:30 竞价点，接纳结束标签 11:30/15:00，排除午休和非本交易日。
- 新浪量为股；腾讯普通沪深、ETF、指数量由手乘 100，科创板 688/689 原始量已为股。
  腾讯缺成交额保留 null，不能把尾字段的换手率当金额。价格保持不复权。
- 启动清理旧采样线与对应指标；有效原生缓存可恢复。缺口中断 CN 指标连续窗口，午休不算缺口。
- 整段预热只计算最新趋势/形态，记录当前实际观测时间，不逐根补写过去的形态事件。
