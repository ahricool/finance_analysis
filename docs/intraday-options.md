# 日内期权交易（V1）

入口：市场 → 日内期权交易，`/market/intraday-options`；仅 US。
分析股票/ETF自身的分钟走势，不读取期权链，不限制0DTE，不选择合约、不下单、不输出盈利概率。
用户明确选择不保存历史：仅Redis最新结果，无数据库表、历史评分归档或回测功能。

## 固定观察池和页面

唯一注册表 `src/finance_analysis/intraday_options/config.py`，固定30个canonical `.US` 标的：
SPY、QQQ、NVDA、IWM、TSLA、AMD、TLT、SPCX、AAPL、MU、AMZN、CRWV、HYG、MSFT、IBIT、GLD、INTC、IREN、SOXL、AVGO、GFL、TQQQ、SOFI、GOOGL、SLV、MARA、MSTR、RIOT、HIMS、META。
不随成交量排名变化；名称批量读Instrument，缺失显示“主数据未识别”，订阅错误另行标记，不替换代码。固定池订阅失败逐标的隔离；连接健康检查失败仍走原有重连，不能把连接故障误当个别代码问题。
观察池不修改任何用户的自选股或持仓。

表格一页展示全部标的，含名称/代码、最新价、当日涨跌幅、15/30/60分钟质量分与带符号收益、当前方向、机会分、当前状态。
每个数据列表头支持升降序，空值始终最后；周期列按质量分，方向/状态按明确枚举顺序。
默认机会分降序。行情每5秒读取缓存，但排序及筛选名单冻结；点击表头、修改筛选/搜索或“更新排序”才更新名单，展开不触发重排。
当日涨跌幅不参与评分，可以与当前方向相反。

点行展开原有 `MarketKLineChart` 的当日原生1分钟K线和成交量。一次只突出15、30或60分钟中的一个窗口。
VWAP有完整成交额时为累计成交额/成交量，否则明确显示HLC3×成交量的近似VWAP；可切换分钟收盘价等权均价。
参考线不参与评分。缺失分钟不补平盘，参考线遇到内部缺口停用；参考线基于已采集区间，非逐笔成交VWAP。
详细指标、门槛系数、集中度、扣分原因与解释来自后端同一个版本结果。

## 时间与数据边界

使用NYSE交易日历的正常时段，包含夏令时、节假日和提前收盘。盘前展示上一交易日并显式标注。
N分钟按真实时间范围取已闭合的原生1分钟K：第一根有效K的开盘价作为起点，随后使用有效收盘价；不跨窗口补根数。
不拼接昨天、不用未闭合分钟、不使用采样/partial分钟。15/30/60分钟按实际开盘依次预热，三个窗口不全时综合分、方向、状态为空。
缺口窗口只要至少有2根有效K就继续计算，返回 available_bars / missing_bars 并标为gap参考分；少于2根才留空。
无效/partial/采样分钟按缺失剔除，不补造平盘；缺口间不可见的路径及波动无法还原，指标为观测数据估计。
三个窗口均可计算时仍输出综合分、方向与状态，不因缺口额外扣分，详情说明数据不完整。

正式结果由Streamer后台每5秒检查，新闭合分钟或最近60分钟评分输入变化时重算，页面关闭也运行。
同一分钟补齐缺口、修订OHLC或修复partial/sampled/有效性标记会刷新最新结果；相同输入仍去重。
接收时间、非负成交量变化、窗口外历史、未闭合及盘后K不触发重算。重连预热按相同规则处理；重启只算最近窗口，不回填历史结论。
盘后K线不触发正式更新，不允许旧分钟覆盖新结果。
最新应闭合分钟有15秒到达宽限；超出仍未收到时标记分钟行情延迟，继续展示及排序已有分数，并标明评分截至时间；不随墙上时间移动窗口伪造新结果。
盘后以收盘边界检查完整性，不把夜间/周末经过时间当成行情延迟。未完整收盘的数据仍标延迟。
报价时间单独检查30秒延迟/超前，不把接收时间当交易所时间；报价标记与分钟评分状态分开。
浏览器响应失败或响应超过20秒未更新时保留上次评分，表格和详情明确标注非当前行情。

## 窗口指标和公式

评分缓存版本为intraday_options_v2；所有阈值都是可解释规则假设，尚未经历史收益校准，不代表统计显著性。
令 `y0=ln(首根open)`，`yi=ln(第i根close)`，`r=yN-y0`，`clip(x)=min(1,max(0,x))`。

- **稳定度 S**：等权线性回归 `y ~ 实际经过分钟数` 的 `100×R²`；零方差为0。
- **路径效率 E**：`100×|r|/Σ|yi-yi-1|`；分母为0时为0。
- **波动尺度 b**：每分钟对数True Range的窗口均值乘 `sqrt(N)`。
  `TRi=max(ln(Hi/Li), |ln(Hi/previousClose)|, |ln(Li/previousClose)|)`，首根previousClose使用自身open。
- **移动强度 M**：`z=|r|/b`，`M=100×clip(z/2)`。价格单位不影响结果，极端移动饱和。
- **扰动控制 D**：用 `sign(r)×(yi-y0)` 把下跌镜像为上涨，再计算收盘路径相对此前峰值的最大逆向幅度。
  `a=最大逆向幅度/b`；`u=最长连续未恢复前高分钟数/N`。
  `D=100×[0.7×(1-clip(a))+0.3×(1-clip(u))]`。这是分钟收盘路径扰动，不等同于逐笔或期权回撤。

基础质量 `Q0=0.30S+0.30E+0.25M+0.15D`。
移动门槛 `g=min(clip(|r|/0.0005), clip(z/0.60))`，窗口分 `Q=Q0×g`。
稳定度与效率共同占60%，不再额外加“顺畅度”分；两者相关，不能当作独立统计证据。
2bp中性门槛和5bp满额门槛是轻量绝对幅度约束，仍可能对低波动债券ETF有影响，不能宣称完全消除了资产类别偏差。

有效方向要求同时满足：`|r|≥0.0002`、`z≥0.35`、`E≥15`、回归斜率与净变化同号；否则中性（0），窗口分上限35。
方向为 `+1/-1`，上涨下跌在对数空间完全对称。显示收益为 `100×(exp(r)-1)`，始终保留正负号。

**脉冲后停滞**：最大单分钟绝对移动/总路径≥60%，且最近5分钟沿原方向净移动小于窗口净移动的15%，窗口分上限35，窗口方向暂按中性，避免把已经停滞的移动描述为仍在延续。
刚发生的急涨/急跌不会立刻被误称为“已经停滞”，需要观察最近5分钟的延续情况。

## 综合分、方向与状态

`B=0.30Q15+0.45Q30+0.25Q60`。
`A=|0.30d15+0.45d30+0.25d60|`，`Score=B×(0.4+0.6A)`。
全部同向时A=1，没有折扣；15分钟反向、30/60同向时A=0.4；15/30同向而60反向时A=0.5。
三个窗口重叠，不解释为三次独立确认。

方向规则按顺序：

1. 30/60同向且非中性 → 沿30分钟方向（允许15分钟回撤）。
2. 15/30同向且非中性，60中性 → 沿30分钟方向。
3. 剩余情况同时存在正、负方向 → 分歧。
4. 其他 → 震荡。

状态优先级和分数上限：

1. 分歧 → 方向分歧，综合分上限55。
2. 震荡 → 等待方向，综合分上限35。
3. 主方向明确但15分钟不跟随 → 回撤观察，综合分上限65。
4. 同向且短线偏离≥2.5 ATR、最近5分钟仍沿主方向移动 → 短线延伸，不额外扣趋势分。
5. 其他同向 → 趋势持续。

短线偏离：最近20根对数收盘价计算EMA（首值初始化，alpha=2/21），最新价与该EMA的绝对对数距离/20根对数TR均值。
这是独立的短期趋势参考，不等同于图上的全天VWAP或共享图表的MA20。

典型解释：平稳持续上涨/下跌的S/E/M较高且扰动浅；上下剧烈震荡净位移小会被E和移动门槛压低；单根拉升后横盘受集中度上限限制；主趋势内短线回撤仍保留主方向但降低机会分；短长趋势冲突标分歧；高质量趋势偏离较远仍高分，但状态提醒等待。

## 技术边界与验证

- 后端独立领域包 `intraday_options/`，纯函数评分与Redis发布/读取分离。
- Streamer默认订阅并集扩展为自选＋持仓＋固定池。复用Longbridge原生分钟线，不新增行情Provider或外部请求链。
- Redis key `rt:intraday-options:intraday_options_v1:{symbol}` 只存最新结果，复用交易日TTL跨周末保留到下一交易日；无历史列表。
- `GET /api/v1/intraday-options` 会话鉴权，只读行情缓存及DB名称；不会在GET中计算指标或拉取外部行情。
- 共享分钟图接口仅给固定白名单额外只读权限，其余证券继续要求本人自选/持仓。
- 页面当前分数、解释、窗口明细同源；前端仅计算图表参考线，不计算趋势评分。
- 暂缓：具体合约、点差/Greeks、0DTE资格、买卖点/止损、推送、历史持久化、胜率校准和自动下单。

检查：`uv run pytest tests/intraday_options tests/market_stream tests/test_realtime_market_websocket.py -q`；
Web `pnpm run build`、`pnpm run lint`、`pnpm run test`、`pnpm exec playwright test e2e/intraday-options.spec.ts`。
