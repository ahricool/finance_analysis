# 日内标的模拟 V7（开盘纯净驱动龙头 · 高胜率与高单笔收益）

观察池 28 只。交易、形态、缓存的版本分别为 `underlying_sim_v7`、`intraday_entry_v7`、`intraday_options_v17`。重启时若仍有旧 V4/V5/V6 模拟仓位，会继续按原仓位冻结的目标位、退出模式与截止时间接收退出报价直至平仓。历史交易保留原版本及冻结证据。

## V7 核心定位与改进（相对 V6）

V7 在 V6 的低频长持基础上，进一步聚焦 **同时提升单笔胜率与单笔净收益**，并同步合入 PR #526 独立代码审查指出的四项执行时点与监测修复。基于 2026 全年 221 个交易日开发检验及零调参外推至真正未见的 2016–2025 十年（2,514 日）与三个外部 IWF 股票池（56 只其他美股）的验证，V7 做出以下升级：

1. **聚焦开盘纯净驱动龙头，移除稀释收益的午间分支**：
   - 仅在 **09:38–10:00 NY**（开盘后第 8 至第 30 分钟收盘）启用 `opening_breakout`（开盘纯净驱动模式）；
   - 默认关闭稀释胜率与收益的 `midday_wave_breakout` 以及 `pivot_breakout`、`trend_recovery`、`box_breakout`、`trend_continuation`（全部保留环境变量开关以便对照回归）。
2. **因果开盘路径效率 + 强动量 + 横向 Top-2 龙头 + 大盘/广度共振**：
   - 5 分钟开盘区间幅度要求 `≥ 0.80%`，且信号分钟必须顺向收在开盘区间外、K 线实体同向（多头阳线 / 空头阴线）；
   - 新增因果 **开盘路径效率门槛 `open_efficiency = |C - O0| / Σ|ΔC| ≥ 0.55`**（淘汰锯齿洗盘假突破）；
   - 当日相对开盘顺向推进提升至 `≥ 2.00%`、相对 SPY 领先提升至 `≥ 1.50%`，本股与 SPY 同在当日 VWAP 顺向侧；
   - 全池 28 标的因果横向排名（`pool_rank_context`，至少 10 只有效标的）仅取 **Top 2 领涨 / Bottom 2 领跌**，且须满足宏观共振：**`|SPY相对开盘| ≥ 0.15%` 或全池同向广度 `≥ 68%`**。
3. **宽幅宏观止损 + 明确波段止盈 + 浮盈锁盈保护（`BE20_Lock20`）**：
   - 放弃 V6 易被早盘正常回踩洗出的 `1.15 ATR` 紧止损与 90 分钟水下早斩；
   - V7 仓位采用 **-2.50% 宏观硬止损**（`INTRADAY_STOP_LOSS_PCT=0.025`）与 **+3.50% 波段止盈目标**（`INTRADAY_TAKE_PROFIT_PCT=0.035`）；
   - 浮盈达到 **+2.00%** 后将保护位自动上移至 **+0.20% 锁盈**（`INTRADAY_PROFIT_LOCK_TRIGGER_PCT=0.020` / `INTRADAY_PROFIT_LOCK_LEVEL_PCT=0.002`，设为 0 可切换为纯 `SL25/TP35`）；
   - 未触及止损、锁盈或止盈的持仓拿满至收盘前 **10 分钟**清仓（常规日 **15:50** / 提前收盘日 **12:50** 纽约时间）；单标的每日最多开仓 **1 笔**。
4. **执行时点与监控修复（合并自 PR #526 审查）**：
   - **同行排名证据时间地板**：`pool_rank_context` 纳入所有候选分钟的 peer 到达/修订时间（含使其失效或降级的修订），避免使用修订前的旧报价成交；
   - **单调报价与保护位修订校验**：退出评估拒绝倒序旧报价（要求 `quote.event_time >= last_price_at`），且旧版结构移动止损收紧等待修订到达后的报价；
   - **停止新进场后持续监测持仓报价**：`10:00` 停止新进场后，只要存在未平仓模拟持仓且未到清仓截止，继续执行行情断流监测与异常告警；
   - **盘中旧状态升级日限保护**：从无 `daily_entry_count` 的 V4/V5 旧状态升级时，自动按当日已消费 `used_processes` 数量初始化日限计数，且旧仓独立沿用原退出路径。

## 入场路线明细

以下按做多描述。做空反转价格比较，使用区间低点或盘中低点。

| 路线 | 默认状态 | 结构、确认与执行 |
| --- | --- | --- |
| 开盘区间突破 / 纯净驱动 (`opening_breakout`) | 启用 | 常规开盘起前 5 根连续真实 K 确定区间（幅度 `≥ 0.80%`）。在开盘第 8–30 分钟（09:38–10:00 NY），每根闭合 K 顺向收在区间外、实体同向、开盘推进 `≥ 2.0%`、开盘路径效率 `≥ 0.55`、相对 SPY `≥ 1.5%`、全池 Top 2 且 SPY 顺向 `≥ 0.15%` 或全池广度 `≥ 68%` 时可执行；入场后 -2.5% 宏观止损、+2.0% 触发 +0.2% 锁盈、+3.5% 波段止盈，15:50 清仓。 |
| 盘中主浪突破 (`midday_wave_breakout`) | 默认关闭 | 60 分钟整理基底突破新日高/低（`INTRADAY_MIDDAY_WAVE_BREAKOUT=true` 且放宽 `INTRADAY_ENTRY_WINDOW_MINUTES=150` 可恢复）。 |
| 箱体突破 / 回测 (`box_breakout` / `box_retest`) | 默认关闭 | 15–30 分钟横向箱体突破与回测（`INTRADAY_BOX_BREAKOUT=true` 可重新开启）。 |
| 整理后趋势延续 (`trend_continuation`) | 默认关闭 | 趋势背景后 3 根窄幅整理突破（`INTRADAY_TREND_CONTINUATION=true` 可重新开启）。 |
| 盘中关键位突破 (`pivot_breakout`) | 默认关闭 | 5 根摆动位单根突破（`INTRADAY_PIVOT_BREAKOUT=true` 可重新开启）。 |
| EMA20 顺势回撤恢复 (`trend_recovery`) | 默认关闭 | 1 分钟均线回撤恢复（`INTRADAY_TREND_RECOVERY=true` 可重新开启）。 |

配置见 `.env.example`，调整环境变量后重启对应进程生效。完整旧路线阈值见[原有规则](intraday-options.md)及[趋势延续](intraday-trend-continuation.md)。
