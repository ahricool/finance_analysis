# 日 K Price Action

`DailyKLineCard` 在浏览器中分析已加载的日线，不增加请求或持久化。
所有复用该组件的详情自然获得此能力。结果只用于研究观察，不参与策略、排名或交易。

## 输入、窗口与上下文

纯函数 `web/src/utils/dailyPatterns.ts::detectDailyPatterns` 接收按交易日升序、日期唯一的 `DailyBar[]`。
每个候选只使用截至形态当日的数据。前置趋势完全排除形态本身的 1、2 或 3 根 K。
需要形态开始前 6 根有效 K，计算其中 5 次收盘变化：

- 看涨反转：累计跌幅 ≥2%，或至少 4/5 次下降且累计跌幅 ≥1%。
- 看跌反转：累计涨幅 ≥2%，或至少 4/5 次上升且累计涨幅 ≥1%。

OHLC 必须有限、正数、最高价大于最低价，且包含开收盘。
上下文和形态窗口中的无效 K、重复/倒序日期会使候选无效，不删除后拼接。
不推断缺失交易日；“交易日前”计数依据已经加载的交易日序列。

## 几何硬门槛

实体 = |收盘−开盘|；振幅 = 最高−最低；影线按实体上下边界计算。

| 类别 | 硬门槛（看跌为镜像） |
| --- | --- |
| 看涨/看跌吞没 | 当前与前根颜色相反；当前实体完整包含前根实体；当前实体/振幅 ≥55%，实体/前收盘 ≥0.5%；前根实体/振幅 ≥20%，实体/自身收盘 ≥0.2%；当前实体 ≥前实体的 1.1 倍 |
| 锤子/射击之星 | 长影线 ≥2 倍实体，短影线 ≤0.5 倍实体；实体/振幅在 15%–35%；实体/收盘 ≥0.2%；不限制实体颜色 |
| 晨星/黄昏星 | 第一根为反向大实体（实体/振幅 ≥55%，实体/收盘 ≥0.5%）；中间实体 ≤首实体30%，且 ≤自身振幅35%；中间实体整体位于首根收盘向首实体内部25%以内或更远的极端方向；第三根为反转方向大实体（实体/振幅 ≥55%，实体/前收盘 ≥0.5%），至少为首实体60%，收盘穿透首实体 ≥60%；不要求跳空 |

## Quality

Quality 是透明规则匹配分，**不是胜率或经统计验证的置信概率**。
所有硬门槛通过后：

```text
Quality = round(40 + geometry × 20 + trend + closeLocation × 10 + volumeBonus)
```

各连续项用 `clamp(x, 0, 1)` 截断：

- 吞没 geometry：`(当前实体 / 前实体 − 1) / 1.5`。
- 影线 geometry：`(长影线 / 实体 − 2) / 2`。
- 星形 geometry：`(收盘穿透比例 − 0.5) / 0.5`。
- trend：`15 × clamp(前置同向累计变动 / 5%) + 10 × 前置同向收盘次数 / 5`。
- closeLocation：看涨 `(收盘−最低)/振幅`，看跌 `(最高−收盘)/振幅`。
- volumeBonus：`5 × clamp((形态日量 / 前置6日有效均量 − 1) / 0.5)`。
  需要至少3个有限正成交量样本；缺失不扣分，也不阻断识别。

只返回 Quality ≥70。调用方可以提高门槛，不能降低到70以下。
同日先筛分数，再按星形 > 吞没 > 影线排序；同级取高分，最后按 type 稳定排序，只保留一个。
目前同级对称形态的硬门槛互斥，仍保留分数决胜规则以便维护。

## 图表与摘要

- 独立 overlay `dailyPattern`，group `daily-patterns`，extendData 包含完整事件与主题。
- 使用短名称、红涨绿跌；看涨放低点下方，看跌放高点上方。
  垂直位置限制在 pane 内，避免极值附近文字被裁切。
- `research-date` 查看日与 `strategy-markers` BST 独立共存。
- `MarketKLineChart` 记录本次创建的 overlay ID，更新时只删除自己创建的 ID。
  移除整个 group/清空 props 也不会残留，不删除用户绘图。
- 全部历史高分事件可以画在图上；摘要仅列最后20根 K 内最近3个，默认展开最近1个。
  点击旧标记仍可查看其完整确定性 reasons，点击摘要可定位。
- symbol/endDate/highlightDate 触发重新加载时清理选择，沿用 AbortController 防止旧响应回写。

## Preview

日线 API 没有逐根 closed/temporary 字段，source 也不能区分混入的今日临时 K。
在获取数据时按响应 market 计算当地日期（CN 上海、HK 香港、US 纽约，Intl 处理夏令时）。

- 日期早于获取数据时的市场日期：Confirmed / 已完成日 K。
- 当日及更晚日期、未知市场：Preview / 形成中。
- Preview 图标带“形成中”、使用普通字重；详情有独立状态框和说明。
- 即使过了名义收盘时间也保持 Preview；不编造交易日历或收盘保证。
  页面跨午夜不自动把可能陈旧的临时 K 升级，重新获取后才重新判定。

Confirmed 仅描述日 K 日期完成状态，不表示价格反转已经被未来 K 验证。
