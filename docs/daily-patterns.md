# 日 K Price Action

`DailyKLineCard` 在浏览器中分析已加载的日线，不增加请求或持久化。
日 K 分为 **15 种蜡烛形态** 与 **结构形态** 两类，周／月 K 不展示。
所有复用该组件的详情自然获得此能力。结果只用于研究观察，不参与策略、排名或交易。

## 输入、窗口与上下文

纯函数 `web/src/utils/dailyPatterns.ts::detectDailyPatterns` 接收按交易日升序、日期唯一的 `DailyBar[]`。
每个候选只使用截至形态当日的数据。前置趋势完全排除形态本身的 1、2 或 3 根 K。
需要形态开始前 6 根有效 K，计算其中 5 次收盘变化：

- 看涨反转：累计跌幅 ≥2%，或至少 4/5 次下降且累计跌幅 ≥1%。
- 看跌反转：累计涨幅 ≥2%，或至少 4/5 次上升且累计涨幅 ≥1%。

蜡烛形态的最少输入为：单根形态7根、双根形态8根、三根形态9根。
十字星同样要求此前6根有效背景，但不使用方向趋势门槛，也不赋予涨跌方向。

OHLC 必须有限、正数、最高价大于最低价，且包含开收盘。
上下文和形态窗口中的无效 K、重复/倒序日期会使候选无效，不删除后拼接。
不推断缺失交易日；“交易日前”计数依据已经加载的交易日序列。

## 几何硬门槛

实体 = |收盘−开盘|；振幅 = 最高−最低；影线按实体上下边界计算。

| 类别 | 硬门槛（看跌为镜像） |
| --- | --- |
| 看涨/看跌吞没 | 当前与前根颜色相反；当前实体完整包含前根实体；当前实体/振幅 ≥55%，实体/前收盘 ≥0.5%；前根实体/振幅 ≥20%，实体/自身收盘 ≥0.2%；当前实体 ≥前实体的 1.1 倍 |
| 锤子/射击之星 | 长影线 ≥2 倍实体，短影线 ≤0.5 倍实体；实体/振幅在 15%–35%；实体/收盘 ≥0.2%；不限制实体颜色 |
| 晨星/黄昏星 | 第一根为反向大实体（实体/振幅 ≥55%，实体/收盘 ≥0.5%）；中间实体 ≤首实体30%，且 ≤自身振幅35%；中间实体整体位于首根收盘向首实体内部25%以内或更远的极端方向；第三根为反转方向大实体（实体/振幅 ≥55%，实体/前收盘 ≥0.5%），至少为首实体60%，收盘穿透首实体 ≥60%；不要求跳空 |
| 倒锤子/上吊线 | 与射击之星/锤子线相同的几何条件；倒锤子发生于此前下跌，上吊线发生于此前上涨；不限制实体颜色 |
| 刺透线/乌云盖顶 | 两根反向大实体，实体/振幅 ≥55%；前根实体/收盘 ≥0.5%，当前实体/前收盘 ≥0.5%；当前开盘在前收盘外侧或等于前收盘，收盘穿透前实体 ≥50% 且 <100%；采用不要求跳空的研究变体 |
| 看涨/看跌孕线 | 前根反向大实体（实体/振幅 ≥55%，实体/收盘 ≥0.5%）；当前反转方向实体完整包含于前实体，大小 ≤前实体50%，实体/振幅 ≥20%，实体/收盘 ≥0.2% |
| 红三兵/三只乌鸦 | 三根同向实体，实体/振幅 ≥55%，实体/收盘 ≥0.5%；收盘逐根同向推进，后两根开盘位于前实体内；方向端影线 ≤实体35%；仍要求整个形态之前存在反向趋势 |
| 十字星 | 实体/振幅 ≤8%，振幅/收盘 ≥1.5%，上下影线各占振幅 ≥30%；中性犹豫观察，非反转或买卖信号 |

## Quality

Quality 是规则匹配质量（rule matching quality），**不是统计置信度（confidence）或胜率（win probability）**。
所有硬门槛通过后：

```text
Quality = round(40 + geometry × 20 + trend + closeLocation × 10 + volumeBonus)
```

各连续项用 `clamp(x, 0, 1)` 截断：

- 吞没 geometry：`(当前实体 / 前实体 − 1) / 1.5`。
- 影线 geometry：`(长影线 / 实体 − 2) / 2`。
- 星形 geometry：`(收盘穿透比例 − 0.5) / 0.5`。
- 倒锤子／上吊线使用影线 geometry；刺透／乌云使用穿透比例；孕线使用 `1 − 当前实体/前实体`；红三兵／乌鸦使用三根实体/振幅的最小值。
- trend：`15 × clamp(前置同向累计变动 / 5%) + 10 × 前置同向收盘次数 / 5`。
- closeLocation：看涨 `(收盘−最低)/振幅`，看跌 `(最高−收盘)/振幅`。
- volumeBonus：仅 Confirmed 历史完成 K 使用
  `5 × clamp((形态完成日量 / 此前最多20根交易日K的有效均量 − 1) / 0.5)`。
  窗口为 `bars.slice(Math.max(0, end - 20), end)`，排除当前完成 K 与未来 K；
  可以包含星形的第1、2根 K。它不同于必须排除整个形态的趋势窗口。
  至少10个有限正成交量样本才启用，不要求完整20根；不足时加分为0，不阻断形态识别。
  Preview 的 volumeBonus 恒为0，盘中累计成交量变化不影响 Quality，也不产生成交量 reason。
  不预测盘中成交量。成交量最多加5分，仅在OHLC与上下文硬门槛通过后参与评分。

十字星独立中性评分：`round(70 + 15×(1−实体占比/8%) + 15×短影线/长影线)`，不使用趋势、收盘位置或成交量加分。

只返回 Quality ≥70。调用方可以提高门槛，不能降低到70以下。
同日先筛分数，再按 **Quality 降序 → specificity priority → stable type** 排序，只保留一个。
只有 Quality 相同时才以三根形态 > 双根形态 > 单根形态作为 UI specificity 决胜规则；
形态复杂度不能覆盖更高的 Quality。最后按 type 稳定排序。

## 图表与摘要

- 独立 overlay `dailyPattern`，group `daily-patterns`，extendData 包含完整事件与主题。
- 蜡烛只画小标记 ▴／▾／◇，红涨绿跌、中性灰色，不把名称与证据画在图中。
  看涨放低点下方，看跌放高点上方，中性放高点上方。
  垂直位置限制在 pane 内，避免极值附近文字被裁切。
- `research-date` 查看日与 `strategy-markers` BST 独立共存。
- `MarketKLineChart` 记录本次创建的 overlay ID，更新时只删除自己创建的 ID。
  移除整个 group/清空 props 也不会残留，不删除用户绘图。
- 全部历史高分事件可以画在图上；两类摘要分别列最后20根 K 内最近3个，默认展开最近1个。
  点击旧标记仍可查看其完整确定性 reasons，点击摘要可定位。
- 悬停图中小标记时在**图下**显示完整证据，移开恢复选中或最近事件；摘要按钮有 Tooltip。
  触屏可点击标记或摘要，均不在 K 线上方铺设大块详情浮层。
- symbol/endDate/highlightDate 触发重新加载时清理选择，沿用 AbortController 防止旧响应回写。

## Preview

日线 API 没有逐根 closed/temporary 字段，source 也不能区分混入的今日临时 K。
在获取数据时按响应 market 计算当地日期（CN 上海、HK 香港、US 纽约，Intl 处理夏令时）。

- 日期早于获取数据时的市场日期：Confirmed / 已完成日 K。
- 当日及更晚日期、未知市场：Preview / 形成中。
- Preview 图标带“形成中”、使用普通字重；详情有独立状态框和说明。
- 即使过了名义收盘时间也保持 Preview；不编造交易日历或收盘保证。
  页面跨午夜不自动把可能陈旧的临时 K 升级，重新获取后才重新判定。

Confirmed 仅描述日 K 日期完成状态，不表示价格反转已经被未来 K 验证。

## 结构形态

`utils/dailyStructures.ts::detectDailyStructures` 生成独立、不可回写的历史事件序列。
支持箱体向上突破／向下跌破、双底／双顶、上升／下降／对称三角形、突破后回踩／跌破后反抽。
以下是本项目初始规则参数，非统一教科书标准，也不代表统计有效性：

| 结构 | 观察窗口与硬条件 |
| --- | --- |
| 箱体 | 分别尝试60／40／20根已完成日 K；上下各至少两次触及且同侧间距≥5根，上下同侧拐点分别跨越至少窗口40%；宽度为最新收盘的3%–25% |
| 三角形 | 同上；上下边界各至少两个已确认拐点，首末同侧拐点跨越至少窗口40%；拟合残差不超过容差；所有 K 在边界容差内；起始宽度≥价格4%，结束宽度>1%，宽度缩至开始20%–80%；上升型上边整体变动≤1.5%、下边上升≥2%，下降型镜像，对称型上边下降≥2%、下边上升≥2% |
| 双底／双顶 | 最多120根历史，至少40根；最近两个连续同侧拐点间隔20–90根、偏差≤3%；中间反弹／回落≥4%，形态前6根至首拐点反向趋势≥3%；中间不得越过极端边界超过0.5%；不跳过中间拐点拼接双顶／底，已在发现前越过颈线的不追溯补发 |
| 回踩／反抽 | 已完成日 K 确认突破后第3–15根；触及原突破位的容差区，且收盘留在突破方向；每个结构仅一次正式回测事件 |

- 拐点严格高于／低于左右各2根，右侧2根也必须已完成。识别日期是可观察到结构的实际日期，不回填到峰／谷日期。
- 基础结构使用此前已完成日 K，**排除正在评估的当前 K**；未知市场日期时不建立结构。
- 箱体／三角容差为 `max(最新历史收盘×0.5%, 窗口平均振幅×0.5)`；双顶／底为颈线×0.5%。
- 边界首次发现后冻结；同类型活动结构重叠时不重复建立，最多跟踪120根。
  三角边界相交而未突破时失效；已突破结构的回测与失效继续使用冻结的原突破位。
- 状态独立为形成中／结构确认／失效；方向明确的结构反向突破即失效。
  箱体／对称三角在突破后确定方向。收盘超过边界容差才确认突破，确认后收盘回到原突破位内侧超过容差则失效。
- 当日事件分为“突破待收盘”“失效待收盘”“回测待收盘”或“当日预演”，不推进正式确认／失效／回测状态；不按名义收盘时间升级。
- Quality 仅为几何匹配分：箱体 `min(90,70+2×上下触及次数)`；三角 `round(75+15×收敛比例)`；双顶／底 `round(80+10×(1−两极值偏差/3%))`。
  未加入成交量、胜率或回测收益评分。门槛至少70。
- 独立 `daily-structures` overlay 在图底部只放 ◆／× 小标记，不显示名称、不覆盖蜡烛。
  同日一个标记按 Quality 选择，**历史结构列表保留全部事件**，可选择同日其他结构。
  只有显式点击时画细虚线边界／颈线／原突破位，悬停不画线；“隐藏边界”可恢复。
- 摘要取每个冻结结构最新状态，避免突破失败后仍推荐旧确认；旧事件可从图中或历史列表查看，按当时证据显示，不借用未来状态。
