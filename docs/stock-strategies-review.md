# 股票策略模块实现 Review（2026-10-22）

本次按已确认需求完成两轮自审，不涉及生产发布。原规则来源为本地 finance_discovery，规则与适配差异见[模块文档](stock-strategies.md)。

## 第一轮：规则与模拟账本

审阅范围：注册表、discovery候选身份、特征、信号和每日账本推进。

发现并修复：

1. MA/动量族的股票和ETF应共同按分数排序，股票优先仅用于CN混合族；补交叉排名用例。
2. 月度动量只在月末入场，回归系统每日补仓/月末检查排名；分开处理并测试。
3. 10/20与10/21的DD触发、暂停和峰值重置分开；ATR/EMA采用连续SMA种子、缺失重置，ETF EMA50上行与五日前比较。
4. 开盘选择不使用执行日收盘、高低价或成交量；未成交退出继续保留，同证券每天最多一次成交。
5. 卖出受阻不阻断其他空位；开盘NAV按有效开盘价估值，与能否卖出分别处理。
6. 信号ATR、数量、成本和止损线随前复权尺度桥接，历史快照保持不可变；增加尺度变化和现金守恒测试。

证据：四项MA/动量策略与原discovery纯引擎的冻结参考比对，120日净值及全部成交匹配。
这验证的是给定冻结特征/候选下的引擎一致性，不等于八项研究历史收益已完整复现。
CN股票优先/ETF独立退出、突破前40过滤、广度、双OFF、DD暂停另有确定性小样本测试。

## 第二轮：持久化、恢复、API与界面

审阅范围：迁移、Repository、单一任务、运行预算、权限、API类型、市场切换、详情与图表。

发现并修复：

1. DD20“达到阈值”直接比较NAV与峰值×80%，避免先计算百分比产生二进制舍入后漏触发；补恰好20%用例。
2. 启动锚点先独立持久化，Universe暂不可用也不改变后续策略起点；状态行锁下原子提交，成功历史拒绝重放/降级。
3. 窗口外估值锚点按精确日期批量补读；同市场共用270日流式标量窗口，避免百万ORM对象及逐股API。
4. 每查询45秒statement timeout/5秒锁等待、每策略最多补5交易日、每轮180秒检查预算、最多10000证券；生产计算链不含远程行情或LLM调用。
5. 部分失败使用TaskOutcome；历史补算计划与尚未补齐的日期明确展示，GET只读。
6. camelCase转换保留证券代码字典键；快速市场切换作废旧响应；管理员单策略检查仍提交同一个Celery任务。
7. 真实浏览器检查发现图表高度为零，改为固定高度父容器；增加可见canvas断言。最终检查390/768/1024/1280/1440/1920px和深浅色。
8. 列表不重复加载完整冻结Universe；只有详情读取元数据。每日账本分页，曲线只返回轻量持久化指标。

PostgreSQL在本次新建的独立临时容器/随机schema中验证JSONB、迁移、两Worker同行序列化与非阻塞市场锁；未使用开发或生产库。

## 验证结果与已知基线问题

- 新增后端聚焦测试35项通过，包括原引擎参考、输入流、API、迁移、失败隔离及实际PostgreSQL测试。
- 相关前端单测20项通过；新增浏览器用例12项通过（含实际可见图表画布）。TypeScript/生产构建通过，改动文件ESLint通过。
- 4041证券×270交易日的合成输入流/共享特征计算耗时14.817秒，外部请求0；该测量不含真实数据库I/O，不能作为生产端到端耗时保证。
- 默认完整后端门禁运行到3073项通过、1项失败；失败为旧`test_removed_domains_are_absent_from_current_schema_and_api`仍断言已存在的portfolio_account/option_contract不应存在。
- 默认完整前端测试934项通过、8项失败：7项Dashboard旧断言和1项原有native-title治理检查。全量ESLint另有既存3项mjs的process no-undef。
- 上述旧失败已在改动前提交`906b2673`的独立checkout复现；本次未修改这些业务页面或放宽原有断言。新迁移带来的current-head断言、任务数量/锁ID及导航断言已同步更新。

最终排除已证实基线失败后：离线后端3074项通过、41项跳过、3项排除（含原有网络排除），92个subtest通过；前端剩余128个文件、933项全部通过。没有将默认完整门禁表述为全部通过。
