# OHLCV 形态与买点机会 V1

本模块是现有 CN/US Trend Universe 的研究机会识别，不是 CAN SLIM、完整 Minervini/Weinstein/Darvas 系统，不管理资金、真实持仓或订单。质量分仅表示规则匹配程度，不是胜率。参数是待时间切分验证的工程初值。

## 计算、身份与数据

- `trend_following/opportunities.py`：纯检测、已知边界跟踪、主分支选择及跨周期投影。复用既有趋势持续时间的至少400个自然日批量DB读取，形态使用最多 180 根；无新行情源、逐股历史请求或查询时扫描。
- Alpha、RSI、旧周期箱体仍使用原 `trend_period + trend_period // 4 + 2` 特征切片。新增形态只由 Trend10 计算一次，窗口不等于趋势周期；Entry 的 MA5/MA10 支撑固定，趋势资格和 ATR 保持各 10/20/40 周期语义。旧周期箱体标签明确与新版冻结边界箱体不同。
- 全部可排名、数据合格股票先计算 Entry/形态，不用 Alpha 前 N 名做机会识别门槛。近期健康上涨资格沿用 Entry V2 的此前 10 个交易日绝对趋势条件，不要求今天 Alpha≥67。
- 记录放入正式快照 `features.opportunities` JSONB，与原快照同事务提交；Preview 使用既有独立表，不推进正式生命周期。没有新增数据库表或迁移。
- `ohlcv_opportunity_v1:code:kind:formation` 结构身份不包含背景周期。均线过程使用触碰日期；同结构跨周期合并、保留 `background_periods`。各周期同一日首事件在统计 SQL 中去重，已记录的事件身份在后续日期也不再计数。
- 保存形成起止、实际发现日期、首次正式确认日期、失效日期、价位、分支质量、证据、未满足条件、数据截止、前复权锚点与模式。不会将峰谷日期冒充发现日期。现存历史快照保留此前确认事实，失效写在后续快照。
- 每次计算以保存的 `anchor_date/anchor_close` 对同一历史日重新读取的前复权收盘价换算边界和绘图点。图表同样按锚点换算到当前展示口径；锚点缺失则不画不可靠边界。该转换假设锚点之前价格按共同复权因子变化；异常历史修订应显式重放。
- OHLC 非正/非有限/高低关系异常、重复日期、窗口内缺交易日均不确认；历史不足单独标记。只提供当前成员回溯，不宣称无幸存者偏差。

## 初始规则

主要参数集中在 `OpportunityConfig`，旧 Entry 参数仍集中在 `TrendFollowingConfig`。

| 分支 | 形成与资格 | 确认及限制 |
| --- | --- | --- |
| MA5 / MA10 | 复用 Entry V2：先上涨、触碰支撑、保持趋势健康，各分支独立 | 收回 0.1 ATR 且恢复；超过 2 ATR 延伸；支撑下破使用既有 0.75 ATR。量能不是此分支硬确认条件，不能称“缩量已确认” |
| 普通突破 / 突破位回测 | 复用原 Entry 条件，保留已知阻力；普通突破确认后跟踪原触发位 | 主分支使用自身质量；回测不借用 MA 分支的状态或分数 |
| 平底 | 前 20 根上涨至少 10%；25/35 根平台、深度 2%–12%、首尾五日均价斜率≤3.5%、收盘区间≤10%；上下沿各至少两次非连续触及 | 不增加短平台冒充经典平底；平台只使用 T−1 及以前数据 |
| 箱体 | 20/40/60 根；复用 `box.py` 宽度、横盘、占用、收缩、触及质量；质量≥70、上下沿各≥2次、斜率≤1.5 ATR，加前置上涨 | 进入跟踪后冻结边界；突破后另观察原箱顶回测，支撑下破 0.75 ATR 失效；不等同完整 Darvas |
| VCP | 最多80根；左右各2根确认峰谷；峰谷回撤≥2.5%去噪；至少2轮，最多取最后3轮；相邻深度比≤1.05，末轮≤首轮0.85，末端宽度≤8%、至少3根 | 回撤阶段末/首平均量比≤0.85；缺量或只有价格收缩保持候选。保存峰谷发生日、可确认日、深度与收缩比；不是 ATR 下降代理 |
| 杯柄 | 最多100根；左高点在前30根，杯底距左至少20根、右侧恢复至少15根；杯深12%–35%、恢复左高90%–105%；杯底附近至少5根，柄5–20根 | 柄深1%至min(12%,杯深/2)，柄位于杯体上半部；柄/杯平均量比≤0.85；尖锐V形、深柄不接受 |

基础流动性采用此前20日均成交额（缺成交额时用前复权收盘×成交量代理），最低1万本币；这是排除极低活跃数据的宽松工程门槛，不是容量或成交保证。新增形态还要求当前价格不低于20日均线且均线不下降。

形态突破共同条件：收盘超过提前已知上沿 0.1 ATR，距上沿≤2 ATR且≤5%，收盘位置≥0.6；当日量/前20日均量≥1.2。距上沿下方3%内为接近触发；量能缺失不伪造严格确认。VCP/杯柄额外要求整理缩量。Preview 的不完整日量不满足严格突破量能条件，所有盘中状态均标“待收盘验证”。

已确认形态保持首次日期；收盘跌破结构失效位，或突破后收回触发位下方0.5 ATR，标失效。形态最多跟踪30个交易日；失败或到期后，只有形成起点晚于旧形成终点的独立结构才重新启动，滚动窗口平移不再发出相同突破。均线回踩失败后需重新具备上涨过程；离开支撑再回到支撑可形成新触碰过程。各分支独立，MA5 失败不否决 MA10。

## 选择、API 与信号中心

主买点只在 `CONFIRMED` 中选择：质量降序、分支名和结构 ID 稳定决胜。主类型、状态、质量、价位、首确认日期来自同一记录；没有有效分支时 `primary=null`，另有 `display` 展示观察结构。兼容 `entry_score` 仍是所有分支最大质量，不能当作执行程度。

`GET /api/v1/trend-following/opportunities?market=CN&trade_date=YYYY-MM-DD&mode=official|preview` 仅读已存结果，按证券和结构合并三个背景周期，返回覆盖数、有效数和截取规则。列表独立于原压缩排名协议，不增大排名缓存；事件研究缓存升级到 v4。正式详情原 features 同样保留完整证据。Preview 日期不匹配返回404。

信号中心合并原 Trend10前30、Trend20/40前10等来源与有效机会前40只；40是完成全池识别后按有效分支质量的输入上限，冻结来源记录总数和截取数。按股票只进入一次LLM，保留确认分支。Prompt仅接收分支结论、关键价格、距离、质量、规则和日期；波段/OHLC不进入Prompt。新增引用路径 `symbol.opportunities.index.field`，显示精度与引用校验一致。明确禁止把机会、趋势和共振中的相同价格事实重复加分。旧冻结输入没有机会字段也可继续使用。

## 视图与证据

趋势页独立“买点机会”，保留原趋势榜。默认有效买点，支持首次确认、观察、延伸、失效、形态和代码/名称筛选；全部数据列排序后分页，空值总在末尾；导出与筛选同源。同票展开选择分支、查看关键价位和峰谷可知日期。日 K 使用独立 `backend-opportunity` overlay，所选后台边界/波段从保存证据绘制，可单独隐藏；前端蜡烛/结构研究不混画。深浅色及移动端沿用既有组件和主题。

## 事件研究和历史兼容

- 保留旧 `PULLBACK_RESUME`（旧 `trend_resume`）、`BOX_BREAKOUT` 等事件定义；新事件为 `OP_*_V1`，覆盖普通突破、MA5、MA10、突破位回测、平底、箱体、箱顶回测、VCP、杯柄及 `OP_STOCK_V1`。
- 分支仅计首次正式确认。证券汇总同日多分支只计一次；已有当前有效主分支时，后续分支确认不重新启动证券事件。SQL按结构身份去除跨周期/跨日重复；日期区间外已有事件也会抑制重复。
- 新机会事件不受页面趋势周期重复切换影响；旧事件保留所选周期。按市场、RISK_ON/NEUTRAL/RISK_OFF和事件版本分组，覆盖缺失与连续有效起点单独展示。
- 5/10/20交易日收盘基准收益、基准超额及完整路径MFE/MAE；另提供下一交易日开盘基准收益、超额及MFE/MAE，区分缺失、未成熟与有效数。开盘基准是假设能按该价成交、零费用零滑点的事件观察，不是可执行回测。
- 不模拟涨跌停/停牌可成交性、T+1、资金仓位、同日止损顺序；缺路径不跳过并伪装完整样本，不输出策略年化。收益评价从当前一致前复权DB日线取价，不能把收盘后信号视作已按该收盘成交。
- 无自动迁移或历史回填。通过已有管理员 `/trend-following/run` 明确指定日期进行顺序重建；这会按当前代码重算指定日期及既有后续链，应先选定范围。旧记录在主动重算前仍显示原版本/新特征缺失；GET不会补算。

## 验证方式与限制

新增合成正反例检验形态、缺量/缺日、已知边界、峰谷右确认、前复权重锚、跨周期去重、Preview不消耗事件、低Alpha候选进入信号中心，以及SQL/Python事件一致性。已有窗口回归检验Alpha/RSI不受额外形态历史影响。浏览器使用离线API夹具验证筛选、跨页排序、展开图表、隐藏overlay、Excel下载与390–1920px布局。

收益有效性尚未经过真实历史样本外验证。建议先冻结V1参数与当前Universe，在互不重叠的训练/验证/最终测试日期区间显式生成快照；只用前段调整参数，后段一次性报告每分支样本数、成熟覆盖、收益分布与市场环境，保留所有失败分支。工程正反例通过不等于实盘收益有效。
