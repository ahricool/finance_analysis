# 日内趋势延续与候选独立性（V3）

## 问题与范围

旧版恢复路线要求两根真实闭合K、最近5根净推进及路径效率；首次确认时可能已离旧EMA触发位很远。
形态2 ATR延伸线与执行1 ATR上限用途不同，过去统一显示“等待确认”掩盖了这种拒绝。
此外，同方向恢复候选在15分钟观察期内阻塞新候选，已交易趋势机会的整个观察期也会阻塞其他趋势机会。

V3保留三条旧路线的确认/距离参数，新增多空镜像的 `trend_continuation`。
只捕捉已有趋势中的真实短暂整理/浅回撤后突破；连续单边大K、无整理的直接跳变不会因此成为新机会。
当前缓存版本 `intraday_options_v13`、形态版本 `intraday_entry_v3_3`、新交易版本 `underlying_sim_v3_3`。
不新增表、真实持仓或notification；不回填历史成交、不重解释已保存旧交易。

## 规则与参数

共同入场规则集中在 `intraday_options/rules.py::RULES`；检测与执行共用 `entry_interval`。
旧箱体/回测确认距离0.2 ATR，旧恢复0.1 ATR，执行上限均1 ATR、形态延伸2 ATR、观察期15分钟。
旧路线ATR仍沿用含补平K的口径，以避免隐性改动其风险尺度；新增分支独立使用真实样本ATR。

新增参数集中在 `rules.py::CONTINUATION` 与 `RULES['trend_continuation']`：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| 趋势背景 | 最多30分钟、至少16根真实K | 全部位于整理之前，不以突破大K证明原来有趋势 |
| 稳定性 / 路径效率 | R²≥0.6 / ≥0.35 | 复用既有回归及路径指标 |
| 顺向推进 | ≥1.5 ATR | 背景首尾真实收盘的有意义位移 |
| 波动尺度 | 最近最多20个TR，至少15个 | 仅相邻真实分钟的True Range；排除补平零波动及跨缺口跳价 |
| 整理形成 / 最长等待 | 3根真实连续K / 自结构起点最多6分钟未突破 | 三根形成后固定边界，不滚动刷新；过时等新结构 |
| 整理宽度 / 回撤深度 | ≤1.5 / ≤1.2 ATR | 深度从背景末收盘到整理逆向极值计算 |
| 整理顺向净漂移 | ≤0.25 ATR | 连续推进不伪装为整理；必须有真实非推进起点 |
| 趋势保护范围 | 背景末5根真实K | 整理逆向极值不能破坏其低点（多）/高点（空） |
| 结构失效位 | 整理逆向边界外0.1 ATR | 与新整理关联，不引用旧恢复EMA |
| 普通确认 | 相邻两根真实收盘越界>0.15 ATR | 第一根真实突破后才能累计确认 |
| 强突破确认 | 越界≥0.35 ATR、顺向实体/振幅≥65%、收盘位置≥80% | 只用于本分支第一根真实闭合突破K |
| 突破K振幅上限 | ≤1.8 ATR | 首次确认前的突破K均检查，包括普通确认第二根；过长则该过程不可进场，不以回到区间洗掉拒绝 |
| 执行距离 | 触发位顺向0.15–0.8 ATR | 每5秒按有效实时报价检查，不能补记触发价/分钟收盘成交 |
| 当前价到失效位风险 | ≤2 ATR | 同时限制结构止损距离，靠近触发位并不自动合格 |
| 形态延伸 | >1.5 ATR | 与报价执行上限不同；普通延伸可按原冻结位恢复，不重设尺度 |
| 候选到期 | 形成后10分钟 | 不等于虚拟持仓到期；尚未突破另受6分钟结构时限约束 |
| 独立推进幅度 | 两次真实推进合计≥0.5 ATR | 配合随后非推进收盘，提供新结构身份，不靠滑动窗口换ID |

这些都是可解释、待验证初值，不宣称最优或具有收益优势。
没有可信结构目标时保持目标与收益风险比未知，新分支不生成测量目标。

## 结构身份与状态

结构起点取“两次相邻真实顺向收盘推进之后，首次非推进真实收盘”的分钟。
三个整理分钟必须真实连续，不能用补平K或未闭合K凑数。
结构起止、上下边界、触发位、失效位、ATR样本数/来源在候选形成时冻结。
首次确认再冻结确认时间与方式；计划由同一组冻结参数得出执行区间。

恢复路线的后续候选需在旧触发之后重新出现真实推进及独立反向行为，并仍满足原趋势和EMA触及条件。
旧候选即使已失效/延伸，也不会仅因状态变化马上重新创建；到期也不能凭原过程自动换ID。
新候选保留旧候选记录，标记 `superseded_by`，旧记录不再执行；单纯延伸且尚无新结构时仍可按原规则恢复。
同一回撤起点的恢复/趋势延续分支共用 `trend:{方向}:{结构起点}` 过程ID。

交易去重继续使用过程ID；新的趋势交易还要求结构起点晚于已交易结构终点和实际进场时刻。
不再只因两个独立结构的观察期重叠就拒绝新结构。旧持久化消费窗口没有结构字段时保留旧保护逻辑。
同标的始终最多一个模拟仓位，无加仓、无同周期退场后再进场；不同标的互不阻塞。

60分钟滚动重建时，不能以被窗口裁掉的背景重建较早候选。过早且缺完整因果背景的记录不重新发现；
当前有效候选的最长背景及生命周期仍在窗口内。首次确认/进场证据留在专用持久化表，不随窗口滚动删除或改写。

`forming`仅表示尚未确认，`confirmed`不表示可下单；`extended`表示形态超过延伸阈值。
`executable`还必须满足实时报价、入场区间、风险距离、截止时间及唯一仓位/去重等条件。
页面显示确认方式和具体拒绝原因，模拟持有仅影响重复开仓权限，不因此隐藏原有效机会分。
历史交易没有新增字段时仍可展示/退场，不补造其确认方式。B/S标记明细、事件与分组统计贯通新形态。

## PR #514审查修订：时序、榜单与身份（V3.1）

本策略是**已有趋势中的整理后延续**，不是“无整理直接启动/追跌”。方向明确本身不构成形态，
必须先有独立真实整理，再完成普通或强突破确认，最后由确认之后的有效报价检查执行区间和结构风险。
本修订不改变普通/强突破阈值、0.15–0.8 ATR执行距离、2 ATR结构风险或至少15个真实TR样本要求。

### 报价与确认顺序

新进场在既有交易日、事件/接收时间、新鲜度检查之外，要求 `quote.event_time >= confirmed_at`。
例如09:54:00确认、09:54:05调度，09:53:50的报价虽然仍在30秒有效期且价格位于区间内，也不能进场。
计划显示“等待确认后的有效报价”，形态仍可保持confirmed；下一轮取得新报价后重新检查区间与风险，
不补记旧触发价。`entry_price_at`保存实际采用的报价事件时间，`entry_at`保存处理时间。
这个附加条件只约束新进场，不约束已持仓退出。

### 榜单使用实际有效分支

`opportunities.primary`仍是最高质量已确认形态，分支明细全部保留。
API新增 `ranked_opportunity`，资格、分数、方向、标签和原因均取该分支，而不借用primary的分数。
候选计划必须通过opportunity_valid、当前规则版本、minute_as_of、实际形态字段一致性及现有时效/截止保护。
同一as_of下的历史修订也必须与计划的冻结字段、状态及质量分一致，错位时先不上榜。

本周期若已自动进场，优先选择实际选中的、仍有效的structure_id；其余按质量分降序、kind与structure_id升序。
执行选择也使用这个稳定排序。自动进场后executable=false只禁止再开仓，不清除opportunity_valid。
无有效计划时ranked_opportunity为空，前端不显示有效分数；原形态仍可作为未执行/历史参考展示。
方向筛选及当前方向列优先使用有效榜单分支；没有有效机会时才使用趋势参考方向。

### 恢复候选身份

恢复候选只在本次触及EMA前**最近10分钟**查找真实“两次推进后非推进”的锚点，这是身份取证边界，
不修改恢复确认/执行阈值。若锚点之后价格已经收回到其回撤前收盘之外，该旧停顿不再属于当前回撤。
首次候选没有合格局部锚点时，以本次真实触及K为起点；后续候选仍必须具有旧候选之后的新独立真实行为，不能靠这个回退重复建立。
锚点推进尺度取候选形成时已知背景ATR，不依赖可能滑出窗口的旧候选ATR。
起止、结构高低、process_id和价格参数全部确定于形成时；同一局部结构的恢复/延续继续共享过程身份并受交易去重保护。

回归案例：09:33有停顿，约56分钟后才触及EMA；下一分钟早期锚点所需K滑出60分钟。
修复前同一structure_id的process_id、结构起点和低点发生变化；修复后从本次10:29触及取证，
所有身份/冻结字段稳定，重启对相同输入重放一致。无新结构连续推进不会因此生成新机会。

### 接收时间与历史版本

公共 `closed_session_bars` 同时要求分钟已闭合、`received_at <= 判断时刻`，先排除未收到版本，再按received_at去重。
原版已收到、修订未到时选原版；只有晚到版时，该分钟在原始选择结果中缺失。
下游允许的时间轴补平不把它变成真实波动/确认样本。修订收到后可更新当前分析，
已持久化的首次确认、entry_evidence和entry_price_at不回写。
调用方无需复制接收时间过滤，也不能从只含最终修订的历史文件还原未保存的原始分钟版本。

四项问题均先用测试复现（修复前10个参数化用例失败），修复后验证；
额外覆盖多空真实数据库写入、稳定选择顺序、快照错位、规则版本及前端使用同一榜单分支。


本轮自查结论：进场报价时序检查与持仓退出隔离；榜单不混用分支或不同分钟修订；
恢复身份仅由候选形成时局部已知证据确定；公共选择入口先过滤接收时间再去重；
旧交易/首次确认依据保持不可变。确认、执行距离、结构风险及真实ATR样本门槛未调整。

### V3.2 恢复候选的历史顺序与确认依据的接收时间

恢复候选按本交易日已收到的分钟依次处理。每个方向记住上一次符合条件的触及时间，
即使该候选已退出60分钟展示窗口。新候选仍以当时的15–30分钟背景判断EMA、波动与趋势，
并从最近10分钟寻找独立回撤。重启时使用相同的当日分钟重建触及记录。
如果历史从盘中才开始，首次触及也需要独立回撤锚点。普通美股交易日有390分钟，Streamer默认保留420根。

`confirmed_at` 为确认K收盘时间。`confirmation_available_at` 取首次确认收盘时间与所用分钟版本接收时间的较晚者。
恢复候选还包含截至形成时用于重建先前触及记录的接收时间。形态重新恢复确认时，
`execution_evidence_at` 记录该次可用时间。每轮进场检查要求报价事件时间已达到该门槛，
并按该报价重新检查价格区间和风险。已有模拟仓位继续按原退出条件处理。

### V3.3 分钟修订恢复进场资格

首次确认保留当时的收盘时间和可用时间。每次确认都记录本次所用分钟版本的最晚可用时间
`execution_evidence_at`。模拟器逐周期保存该分支实际接受的最早报价事件时间 `entry_quote_not_before`。
同一结构持续确认时可沿用已经观察到的确认依据，报价仍须通过新鲜度、区间和风险检查。
若模拟器已观察到结构失效，随后修订使其恢复，即使按修订后的分钟重放会得到连续确认，
也须等到修订接收时刻或之后的报价。若调度跳过了原版，首次看到该分钟时只有收盘后到达的版本，
同样以该版本的接收时间作为门槛。重启后从已保存计划继续执行此门槛。

多空镜像回归中，09:54 首次确认时价格越界。09:55:05 原版分钟已使形态失效。
09:55:14 收到修订，09:55:15 复算时仍保留原首次确认并拒绝 09:55:03 的报价。
09:55:23 的新报价若在区间内，以该报价模拟进场并保存价格时间；若已越界则继续空仓。
